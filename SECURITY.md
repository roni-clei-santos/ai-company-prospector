# Política de segurança · Security policy

[Português](#português) · [English](#english)

## Português

### Como reportar uma vulnerabilidade

Reporte de forma privada pelo GitHub: na página do repositório, abra **Security > Report a vulnerability** ([link direto](https://github.com/roni-clei-santos/ai-company-prospector/security/advisories/new)). Só quem mantém o projeto vê o relato.

Não abra uma issue pública para falhas de segurança.

Ajuda incluir: o arquivo ou comando afetado, o sistema (macOS, Linux ou Windows), os passos para reproduzir e o impacto esperado. Use só dados fictícios; não envie dados pessoais reais (perfil, planilhas, rascunhos, prints).

### Escopo

- Scripts em `scripts/` e `.github/ci/`
- Skills em `skills/` (incluindo `skills/_shared/`) e o `PROMPT-prospeccao.md`
- Instaladores `install.sh` e `install.ps1`

Fora do escopo: falhas do Claude Code, da extensão Claude in Chrome, do LinkedIn, do Gmail ou de outras ferramentas de terceiros (reporte direto a quem as mantém).

### Prazo

Você recebe uma primeira resposta **em até 7 dias**.

## English

### How to report a vulnerability

Report it privately through GitHub: on the repository page, open **Security > Report a vulnerability** ([direct link](https://github.com/roni-clei-santos/ai-company-prospector/security/advisories/new)). Only the maintainers can see the report.

Please do not open a public issue for security problems.

It helps to include: the affected file or command, the system (macOS, Linux or Windows), steps to reproduce and the expected impact. Use only fictitious data; do not send real personal data (profile, spreadsheets, drafts, screenshots).

### Scope

- Scripts in `scripts/` and `.github/ci/`
- Skills in `skills/` (including `skills/_shared/`) and `PROMPT-prospeccao.md`
- The installers `install.sh` and `install.ps1`

Out of scope: issues in Claude Code, the Claude in Chrome extension, LinkedIn, Gmail or other third-party tools (report them to their maintainers).

### Response time

You will get a first response **within 7 days**.
